## How to read the states

| State | Meaning |
|---|---|
| `open` | No remediation landed. |
| `implemented` | Code changed toward the finding's requirement. |
| `tested` | A regression that failed before the fix now passes. |
| `integrated` | The changed code runs in the advertised production path. |
| `evaluated` | An independent measurement artifact exists (`docs/*.json`) and is linked. |

States are cumulative only where noted; `evaluated` is always the
strongest honest label, and a `partial` note means the finding's
original requirement is not fully met — residual scope is named, never
silently dropped.
